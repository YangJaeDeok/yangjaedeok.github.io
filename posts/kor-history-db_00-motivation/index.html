선요약 : SQL + 한능검 공부


2026년 상반기에 석사과정을 졸업하고 취업 준비를 시작했습니다. 20대 내내 대학에만 있다가 막연하게 취준 하려고 보니 뭐부터 해야할지 몰라서, 일단 필요해보이는 자격증부터 따보기로 결정했습니다. ‘취업 공부를 하다보면 뭐라도 보이지 않을까-’ 하는 생각이 들었거든요.

IT와 전산 쪽으로 가닥을 잡고 공부를 시작했는데 따야할 온갖 자격증이 너무 많더라구요. 공부하면서 드는 생각은

“이걸 왜 학위과정 하는 동안 안했지” “AI 때문에 다 망해가는 업계에 왜 이제서야 관심을 가졌지”

… 후회 막심한건 고사하고 일단 발등에 불 떨어졌으니, 여러 자격증 취득을 시도했고 다음의 결과를 얻었습니다

  • 리눅스 마스터 2급 필기

  • ADsP

  • 정보처리기사 필기

  • 네트워크 관리사 2급 필기

사실 IT 자격증 중 기본 중의 기본인 SQLD는 못땄습니다. SQL 체득이 잘 안됐었는데, 개념과 쿼리문을 봐도 직접 해본 적이 없으니 소위 말하는 ’뇌컴파일’이 아예 안되는 수준이었거든요. 연습하기에는 적절한 자료도, 서버도 없던 터라 개념서랑 풀이서만 봤는데 그게 생각보다 안됐습니다.

나머지 자격증 실기 시험도 빨리 봐야하는데 부트캠프랑 병행하기는 벅찼다는 핑계를…

한창 그렇게 자격증 공부하다가 한국사능력검정시험도 알게 됐는데, 어렸을 때부터 역사에 관심이 많았던 터라 ncs가 아니더라도 이건 반드시 따야겠다 싶었습니다. 그렇게 심화 준비를 했는데, 단기간에 암기하기 힘들고 필수 자격증은 아니라는 안일함에(…) 의지 부족이 겹쳐서 계속 낙방했습니다.

학창시절부터 한국사가 다른 사람의 연애사와 비슷한 특성을 지니고 있다고 생각할 때가 많았는데 이유인 즉슨 ‘들을 땐 재밌고 흥미진진한데, 복기하려면 기억이 잘 안나고 굳이 이것까지 알아야하나’ 싶어서…

어쨌든 이 두마리 토끼를 다 잡기 위한 방법으로 생각해낸게 한능검 공부를 SQL로 해보자는 것이었습니다. 두마리 토끼를 다 잡을 수 있을지, 다 놓칠지는 모르겠지만 부트캠프에서 배운 MariaDB 실습용으로는 훌륭한 소재인 것 같아서 시도해보려 합니다.

참고

한국사 DB 자체는 국사편찬위원회에서 국가사업으로 구축되어 있습니다

https://db.history.go.kr/

하지만 이 정도의 DB를 개인이 보유할 이유도 없거니와, 너무 많은 정보를 담고 있다보니 SQL 실습 + 한국사능력검정시험 심화 공부 목적 선에서 개인 서버에 한번 구축해보기로 했습니다.

프로젝트 구성

집에 구축한 홈랩에 DB를 적재합니다. 홈랩 구축에 대한 포스트는 여기에서 확인할 수 있습니다.

Proxmox 기반 NAS에 MariaDB용 LXC를 올리고, 해당 LXC에 제 맥북과 홈랩의 클로드 코드가 접근 가능하게끔 설정해줬습니다.

Proxmox에 MariaDB LXC 설치 스크립트 에서 명령어를 복사하고, host의 셸에 입력하면 설치됩니다.

var_os='debian' bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVE/main/ct/mariadb.sh)"

DB 서버의 세부 설정은 개인 취향대로 하면 됩니다.

GitHub Repository

부트캠프에서 프로젝트 몇 개를 해보니, 협업 목적으로 레포지토리를 쓰는 방법을 배웠습니다. 쓰기 전에 생각했던 것보다 훨씬 더 프로젝트 관리에 유용하기에, 개인 레포지만 마일스톤과 이슈, PR을 연습해보려고 합니다.

그냥 main 브렌치에 커밋푸시하는 것보다는 조금 더 다채롭게 쓸 수 있을 것 같기도 하고, 면접에서 DB를 다뤄본 적이 있는지 묻는 질문에 보여드릴 포트폴리오로 쓸 수도 있을거라고 생각이 듭니다.

진행에 따라 변할 수도 있지만, 큰 틀에서 레포 폴더 구조는 다음과 같습니다.
